# Windows icons, smaller installers and GPU process visibility

task_master v1.0.5 applies the app logo to the Windows taskbar, executable and
shortcuts, reduces installer downloads, and makes process membership clearer
when monitoring multiple GPUs.

## Fixed

- Windows sets the app window icon before displaying the window and embeds a
  multi-resolution icon in the executable. Installer and Start menu shortcuts
  use the same branding. Existing pinned shortcuts may need to be unpinned and
  pinned again after updating.
- Remote helper path handling compiles cleanly on Windows and macOS as well
  as Linux.

## Changed

- Installers contain only their own native collector and runtime. Remote
  collectors and Windows sensor runtimes are published as separate release
  assets and downloaded for the detected OS and architecture when needed.
- Remote helpers must match the desktop's exact release version. Downloads are
  verified against signed metadata and cached for reuse. Compatible installed
  collectors remain usable without downloading a helper. The first uncached
  download requires internet access on the local machine.
- Linux packages strip staged binaries and use stronger compression. Windows
  sensor publishing removes unused assemblies while retaining hardware
  backends, reflection and WMI/COM support. Windows and macOS installers also
  use stronger compression.
- The GPU process table shows processes belonging to other GPUs in grey while
  retaining the existing process sorting, grouping and controls.

## Downloads

Choose the installer matching your system: Linux x64/ARM64 AppImage or Debian
package, Windows x64/ARM64 setup executable, or macOS Intel/Apple Silicon
package. The release also includes six native collectors, two Windows sensor
archives, combined SHA256SUMS and the signed updater manifest.

Existing installations can update through Updates or install manually. Use
Setup / fix to update installed remote collectors.
