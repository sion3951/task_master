# task_master v1.0.7

- Pin a history sample to inspect its recorded CPU, RAM and GPU process consumers across Overview, CPU, GPU and Mem+IO. Process snapshots follow remote machines, graph freezing and Persistence reloads.
- Keep local telemetry sampling on a dedicated worker so UI rendering can continue independently.
- Reduce Linux history and font memory use while retaining the five-minute history window and recorded process data.
- Support Unicode names and messages through available font fallbacks, with consistent text measurement and UTF-8 truncation.
- Improve Overview layout in shorter windows and add process tables beneath resource histories.
- Harden Linux and macOS updates with protected native helpers that independently verify signed metadata and installer contents after elevation.

Linux and macOS installations from older releases require one manual installation of a current release package to enable the protected update helper.

The release workflow builds Linux AppImage and Debian packages, Windows setup executables, macOS installer packages, remote collectors, and signed update metadata for x64 and ARM64.
