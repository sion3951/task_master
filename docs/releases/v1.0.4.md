# Native Windows ARM64, networked PCs and broader GPU telemetry

task_master v1.0.4 adds a native Windows ARM64 installer, improves remote-PC
setup and monitoring, expands GPU telemetry, and moves macOS graphics to Apple's
native frameworks.

## Added

- Native Windows ARM64 desktop, headless collector and sensor-helper runtime,
  alongside the x64 installer. Windows ARM64 builds download the matching native
  package through Updates. Every desktop includes both Windows collector
  architectures for SSH monitoring.
- Linux DRM/sysfs/fdinfo GPU telemetry for supported AMD, Intel and Qualcomm
  drivers, including available activity, memory, clocks and hardware sensors.
- Windows DXGI/WDDM GPU discovery, activity and process-memory readings, with
  optional AMD/Intel GPU sensors from the installed sensor helper. Integrated
  adapters display shared GPU allocations as GPU RAM.
- New task_master branding assets.

## Changed

- Networked PCs keeps saved PCs visible even when they are unreachable or need
  SSH authentication. Discovery presents suggestions with Add PC, allowing users
  to choose which hosts to monitor.
- Each monitored PC has Retry now, Setup / fix, Terminal and Delete PC controls,
  with connection state, last-sample age and setup messages.
- Setup / fix reports six stages from SSH access through collector installation
  and sensor permissions, and verifies fresh telemetry before reporting success.
- Remote protocol v6 identifies the collector, architecture, installed/temporary
  mode and session. Sequence checks and source timestamps improve remote history
  continuity and expose sampling gaps. Older incompatible installed collectors
  fall back to the bundled temporary collector until reinstalled.
- macOS uses AppKit, Metal and CoreText for its window, GPU rendering and fonts,
  retaining screenshots and pipeline caching while removing GLFW, FreeType,
  Vulkan and MoltenVK runtime dependencies. Installers target macOS 13 or newer.

## Fixed

- Clicking the background closes Networked PCs and consumes the click so it does
  not activate dashboard controls underneath.
- Retry now and successful setup can reconnect one remote PC when Persistence
  owns its worker, without restarting other monitored PCs.
- Unknown or changed SSH host keys pause retries with an actionable setup
  message; saved PCs and setup failures remain visible.
- Windows ARM64 packages verify the architecture of the desktop, collector and
  sensor executable, preventing x64 payloads from being labelled ARM64.
- Release collectors report the package version in connection details.

## Downloads

Choose the package matching your system:

- Linux x64 or ARM64: AppImage or Debian package.
- Windows x64: `task_master-1.0.4-windows-x64-setup.exe`.
- Windows ARM64: `task_master-1.0.4-windows-arm64-setup.exe`.
- macOS Intel or Apple Silicon: the matching `.pkg` installer.

The release includes combined SHA256SUMS and the signed updater manifest.
Existing updater-enabled installations can use Updates; manual installation is
also available. Use Setup / fix to update installed remote collectors.

GPU readings depend on the driver and available hardware interfaces. The Windows
CPU sensor provider supports Intel/AMD x64; ARM64 CPU package watts and hardware
sensor clocks remain unavailable through that provider. Native macOS graphics
runtime behaviour still needs verification on Mac hardware. See the
[README](https://github.com/sion3951/task_master/blob/v1.0.4/README.md) for platform
requirements and telemetry details.
