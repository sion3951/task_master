# Inter typography and native Windows downloads

task_master v1.0.6 switches the entire app to Inter and removes the Windows
updater's dependency on curl.

## Changed

- Inter Regular replaces DejaVu Sans in every app view on Linux, Windows and
  macOS. The font is embedded in the executable and works without installing
  system fonts. The bundled font license and CPU graph concepts are updated.

## Fixed

- Windows update checks, installer downloads and uncached remote helper
  downloads use the built-in Windows PowerShell/.NET HTTPS client instead of
  requiring curl. Downloads use Windows certificate trust and proxy settings,
  stream to disk, enforce size and time limits, and follow only HTTPS redirects.
- Windows download failures now point to connection and Windows HTTPS/proxy
  settings. Signed metadata and package checksum verification remain required.
- Linux and macOS retain their existing curl download transport, including the
  private curl executable bundled with Linux AppImages.

## Downloads

Choose the installer matching your system: Linux x64/ARM64 AppImage or Debian
package, Windows x64/ARM64 setup executable, or macOS Intel/Apple Silicon
package. The release also includes six native collectors, two Windows sensor
archives, combined SHA256SUMS and the signed updater manifest.

Existing installations can update through Updates or install manually. Use
Setup / fix to update installed remote collectors.
