# ui fixes

task_master v1.0.1 improves dashboard alignment, spacing and memory/I/O summaries.

## Changes

- Match top, bottom, left and right outer padding, including header controls and
  their click targets.
- Align graph scale numbers and left time labels with their headings across
  Overview, CPU, GPU and Memory + IO.
- Align Overview dividers with the bottom of the Now label.
- Rename Memory + Disk to Memory + IO and reduce the title/navigation space.
- Hide unconfigured swap/pagefile graphs and summaries, giving the space to RAM
  and I/O. Hide a swap summary when its inspected sample has no swap.
- Show available/total RAM beneath RAM used, and remove redundant memory and CPU
  headings, footer notes and their reserved space.
- Show Total bytes and Max rate for disk read/write and network receive/transmit
  since persistence was last enabled. These reset when persistence is enabled,
  survive window/service restarts and retain background observations beyond the
  graph window. Totals integrate recorded rates and omit disconnected intervals.

## Downloads

The Installers workflow attaches Linux x64/ARM64 AppImages and Debian packages,
the Windows x64 setup executable (also supported by Windows 11 ARM64 emulation),
macOS Intel/Apple Silicon packages and combined SHA256SUMS after builds finish.

Platform requirements and existing telemetry limitations are unchanged; see the
[v1.0.0 release notes](https://github.com/sion3951/task_master/releases/tag/v1.0.0).
