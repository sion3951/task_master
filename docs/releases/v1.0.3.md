# Automatic updates and hardware selection

task_master v1.0.3 adds signed automatic update downloads, per-machine CPU/GPU
selection, and improvements to persistence and Windows installation.

## Changes

- Check the latest stable GitHub release in the background and download the
  matching Windows, macOS, Debian or AppImage package. Open **Updates** to check
  immediately, change automatic downloads, or **Update and restart**. Updates
  require a valid Ed25519 signature and the signed package size and SHA-256.
- Reuse native installers to update the desktop and local hardware helpers,
  stopping persistence without disabling it and relaunching as the ordinary
  user. AppImages include curl and its private runtime libraries.
- Select GPUs and CPU sockets with arrows in their dashboard headings. Each
  machine remembers its selected devices for the current session; graphs,
  frozen views and readouts use the selected device's history. GPU process
  tables continue to cover all GPUs.
- Retry NVIDIA device discovery if the driver is unavailable at persistence
  startup. Retain fresh desktop GPU readings and graph continuity during the
  handoff to background sampling.
- Refresh changed Windows persistence dependencies and restore missing scheduled
  tasks while retaining saved settings, graph history and accumulated I/O.
- Bundle the pinned, signature-verified official PawnIO installer with Windows
  setup and remote installation payloads. Sensor preparation displays progress,
  logs timings and uses parallel runtime copies without requiring a download
  during installation.

## Downloads

Install the matching release package: Linux x64/ARM64 AppImage or Debian package,
Windows x64 setup (also used through Windows 11 ARM64 emulation), or macOS
Intel/Apple Silicon package. The release includes combined `SHA256SUMS`,
`update.json` and `update.json.sig`.

Install this first updater-enabled release manually. Subsequent signed stable
releases are available through **Updates**. Installation asks for administrator
authorization when needed; automatic downloads do not install unattended.
Development builds and manual source installations are updated manually.
Existing remote collectors retain their separate **Install / fix** action.

Existing platform requirements and telemetry limitations still apply; see the
[README](https://github.com/sion3951/task_master/blob/v1.0.3/README.md) and
[updater documentation](https://github.com/sion3951/task_master/blob/v1.0.3/docs/updater.md).
